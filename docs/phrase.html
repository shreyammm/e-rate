How this works

All 12 published JSONL source shards are read and the expected filing counts checked. Each filing's original text is scanned without using an AI model. Phrase options are evaluated as literal case-insensitive substrings. Nearby language is detected in overlapping 1,500-character windows, rather than inferred semantically. Long filings count once; no commenter is assumed to be a distinct person. Search results are complete for the specified literal matching rule, not for all possible synonyms or arguments.
