4. Trustworthiness and research limitations

Actual claims are retained at the individual filing level. 1,594 published machine excerpts have been checked against the source-text file and their offsets. This proves that the quotation exists, not that the commenter endorsed it or that the model's interpretation is correct.

  • No sample extrapolation: all completed records were used to calculate these counts. Pending filings are excluded from stance totals and shown in the denominator.
  • Attribution: distinguishing a filer's views from FCC wording, copied campaigns, opposing arguments and cited attachments remains a major source of possible error.
  • Long-document flag: each source file was available for lexical scanning, but the deadline-specific model pass may select high-signal passages rather than read megabytes of quoted appendix material. These filings are explicitly labeled.
  • Repeated submissions: one filer may submit several documents; normalized text hashes allow one sensitivity check, but template similarity and verified entity counts require separate validation.
  • Semantic clusters: unsupervised clusters can combine differing stances or split paraphrases; they are discovery aids, not finalized substantive themes.
  • Self-selection: FCC commenters are not a probability sample of the public, so no filing-weighted percentage should be described as public-opinion support.

Completion standard: filing coverage, attribution accuracy, argument-family coherence, role validation and full source drill-through need to be documented before moving these figures into a final policy-analysis claim.
