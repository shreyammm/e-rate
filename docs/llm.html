How is this generated?

Free Ollama inference runs in scheduled GitHub Actions batches, analyzing full comments in overlapping windows. It extracts requested actions, provision positions, cited arguments and inferred roles. The code rejects evidence quotes that cannot be located exactly in their original source window. Every filing has a resumable, hashed checkpoint.

This experimental lane never overwrites the human-validated findings. The model may find arguments keyword retrieval misses, but an exact quote only verifies the quotation, not the LLM's interpretation. Full methodology and cautions ↗
