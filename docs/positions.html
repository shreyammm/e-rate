Publishable counts require validation

How we'll move from leads to credible numbers

1. Every filing considered

Search all 3,230 readable source texts and all available Kaggle claims. Flag both positive and contrary evidence and separately identify missing or low-quality source coverage.

2. Source-exact adjudication

Code what the filer endorses, not a quoted FCC proposal. Separate ending E-Rate from cutting particular subsidies; concern about screen time from mandating limits; alleging misuse from calling for better oversight.

3. Randomized error audit

Sample both model-flagged and model-negative filings for false positives and missed arguments. Double-code contested and potentially reputational allegations. A one-person browser review is not an independently validated census.

4. Report real denominators

Publish counts as distinct filings, then verified organizations and distinct people only where identity is confirmed. Preserve duplicates and disclosed template clusters. Report unclassified filings rather than treating them as neutral.
