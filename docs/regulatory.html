Why this is a secondary framework

Counting mentions of FCC options is different from discovering what motivated filings. The option framework can help answer “what should the FCC do about a particular rule?” but does not, by itself, capture local control, financial burden, educational opportunity, or cross-cutting arguments.

For those questions start with the Argument Atlas; use this page to make a later, source-reviewed connection to the actual rulemaking. Machine interpretations from GitHub and Kaggle remain a third and separately labeled analysis layer.
