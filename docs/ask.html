Ask the FCC comment corpus

Ask a question in plain English. For every question, the tool re-scans all 3,231 filing records (3,230 readable comment texts), searches for relevant and contrasting passages, and uses Microsoft Phi-3.5 Mini (US-developed, MIT open-source license) running on your computer to read every readable filing in full, window by window, then merge all source-verified extracted claims into a cited synthesis. No lexical search shortlist is used to select which original filings the model examines. A broad full-corpus run may require many hours; keep this tab open, or resume saved checkpoints later. There is no paid API or account required.

Try a question

Free model requirements

The first generated answer downloads a quantized Microsoft Phi-3.5 Mini model (several GB), cached by your browser. It requires a WebGPU-compatible browser and sufficient GPU memory (about 3.7 GB model VRAM). The model processes EVERY readable original filing in overlapping full-text windows (rather than only lexical search hits). This can require thousands of model calls and many hours. Keep your browser tab open. Completed source-window and synthesis checkpoints are stored locally in your browser for resumption of the same question; you can cancel and restart. On unsupported devices, you can still search and inspect evidence.

This is a GitHub Pages static website. It does not transmit your question or retrieved filing excerpts to a paid inference API. Model weights load from WebLLM / Hugging Face and inference runs in your browser.

Important research boundaries

Every question re-reads the full set of source filings (about 78 MB compressed; browser caching may reduce repeat downloads). The entire original text of every readable filing is passed to the on-device model in overlapping windows, independent of lexical matches. Only after all original windows are completed does it merge the source-verified extracted claims into an answer. The complete window-by-window claim ledger is exportable. No LLM can guarantee perfect recall or interpretation of every claim; summarization is necessarily lossy even when every window is processed. Search matches are not a representative sample and cannot substantiate support/opposition percentages. The tool does not verify external factual assertions.

For additional per-filing semantic evidence, use the separate Kaggle GPT-OSS / Granite census; those model classifications require validation. One FCC submission is not necessarily one distinct person. The corpus is an October 20, 2026 snapshot, not a live FCC feed.
