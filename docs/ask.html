Free model requirements

The first generated answer downloads a quantized Microsoft Phi-3.5 Mini model (several GB), cached by your browser. It requires a WebGPU-compatible browser and sufficient GPU memory (about 3.7 GB model VRAM). On unsupported devices, you can still search and inspect filing evidence. Subsequent answers reuse the loaded model.

This is a GitHub Pages static website. It does not transmit your question or retrieved filing excerpts to a paid inference API. Model weights load from WebLLM / Hugging Face and inference runs in your browser.

Important research boundaries

The retrieval results are not a representative sample. The system cannot infer that most commenters support or oppose something, calculate a valid percentage from search hits, or verify factual assertions in filings.

For population-wide patterns, use the separate Granite per-filing census once processing is complete. One FCC submission is not necessarily one distinct person. The corpus is an October 20, 2026 snapshot, not a live FCC feed.
