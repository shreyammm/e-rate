# Unpublished source-based identity research

**Branch:** \`research/identity-562-unpublished-20261102\`

This is an experimental investigation, deliberately separated from the live
website, \`main\`, \`docs/data\`, the authoritative player registry and stakeholder
census. Do not merge or cherry-pick automatically.

The cohort consists of *filings* whose old player role is
\`named_person_capacity_unstated\`. The published figure of 562 refers to
**distinct normalized FCC submitter fields**; there were 567 filings in that
group at the October 2026 source snapshot. An unstated profession is not an
unknown person's identity.

All original source shards are checked against manifest SHA-256. The script
looks for first-person professional and civic capacity evidence and
near-duplicate coordinated form-letter participation. It preserves evidence
pattern IDs, source links, multiple possible capacities and confidence, rather
than overwriting roles. A school affiliation is **not** authorization to
speak on behalf of a district; a repeat name is **not** verified employment.
A template match alone is not proof of advocacy organization membership.

When run, the branch workflow publishes only privacy-minimal
\`research/identity_562/results/*\` **on this research branch**. It does not
update GitHub Pages, \`docs\`, \`main\`, or production category totals.
