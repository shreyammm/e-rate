# FCC E-Rate Public Comment Observatory

Reproducible research tooling for analyzing FCC E-Rate public comments. The initial research pipeline, tests, dashboard, and methods are being added through a reviewable pull request.

**Research caution:** The dataset is a time-bounded snapshot. A retrieved document is not necessarily a readable document, and public comments are not a representative public opinion poll. No raw comments, personal contact records, or credentials belong in this source-code repository.
